\# 07 \- Hero Composition & Choreography

\> Version 1.0  
\>  
\> This document defines how the hero is composed, how attention moves through it, and how every element works together to create a memorable first impression.  
\>  
\> It does not define UI styles or animations.  
\>  
\> It defines visual hierarchy, spatial relationships, camera philosophy, and user perception.

\---

\# 01 — Hero Philosophy

The hero is not a banner.

It is not a landing section.

It is not a marketing component.

The hero is the opening scene of the entire experience.

Visitors should feel they are entering a carefully engineered environment rather than opening another portfolio website.

Every decision inside the hero must reinforce one belief:

\> \*\*"This person transforms business complexity into engineered clarity."\*\*

The environment exists to support that belief.

Typography exists to explain that belief.

Motion exists to demonstrate that belief.

Nothing exists purely for decoration.

\---

\#\# Layer 01 — Canvas

Purpose:

Provide calm.

The canvas should disappear.

It should never become a visual element itself.

Characteristics

\- Warm off-white background  
\- Large negative space  
\- No gradients  
\- No textures competing for attention  
\- Feels like premium paper rather than a webpage

The visitor should never consciously notice the background.

\---

\#\# Layer 02 — Lighting

Purpose:

Create atmosphere without becoming dramatic.

Lighting should feel natural.

Not cinematic.

Not futuristic.

Not theatrical.

Characteristics

\- Soft daylight  
\- Long gentle shadows  
\- Low contrast  
\- No glow  
\- No bloom  
\- No lens flare

The lighting should quietly make everything feel physical.

\---

\#\# Layer 03 — Environment

Purpose:

Create curiosity.

This is not decoration.

It is the visual metaphor for Huzaifa's thinking process.

The environment should feel engineered rather than designed.

Characteristics

\- Minimal structural language  
\- Controlled geometry  
\- Clear organisation  
\- Large areas of emptiness  
\- Strong balance

Avoid obvious architectural references.

The visitor should never think:

"This is a building."

Instead they should think:

"This space represents a way of thinking."

\---

\#\# Layer 04 — Visual System

Purpose:

Demonstrate transformation.

This is the protagonist of the hero.

Everything else supports it.

The visual system represents:

Business complexity

↓

Engineering judgement

↓

Organised systems

↓

Reliable operation

The transformation must be immediately understandable.

Not technically.

Emotionally.

Visitors should feel order emerging.

Not watch an animation.

\---

\#\# Layer 05 — Actions

Purpose:

Invite conversation.

Buttons should never compete with the story.

Characteristics

\- Calm  
\- Quiet  
\- Minimal  
\- Clearly secondary to the headline

Primary CTA

Start a Project

Secondary CTA

View Selected Work

Nothing animated simply to attract attention.

Confidence never asks to be noticed.

\---

\# 03 — Visual Hierarchy

The hero should guide attention naturally.

Never force it.

The visitor's eye should follow this exact journey.

3

↓

↓

↓

\`\`\`

If visitors notice the navigation before the headline,

the hierarchy has failed.

If visitors notice the buttons before understanding the message,

the hierarchy has failed.

If visitors remember the animation but not the positioning,

the hierarchy has failed.

\---

\# 04 — Attention Principles

The eye should never search.

The design should gently lead attention.

Every screen should contain one dominant element.

One supporting element.

Everything else becomes context.

Think editorial design.

Not dashboard design.

\---

\#\# The Rule of One

Every viewport has:

One hero.

One message.

One action.

Never two competing focal points.

\---

\#\# Negative Space

Whitespace is not empty.

Whitespace creates confidence.

Large areas of calm increase perceived quality.

Resist the temptation to fill space.

If something can be removed without reducing understanding,

remove it.

\# 05 — Desktop Composition

The desktop hero is not divided into equal columns.

Avoid the common 50 / 50 portfolio layout.

The composition should feel editorial rather than symmetrical.

The environment and the content should support one another without competing.

\---

\#\# Layout Ratio

\`\`\`  
┌──────────────────────────────────────────────────────┐  
│                                                      │  
│                        Environment                   │  
│                     (Visual Story)                   │  
│                                                      │  
│                                                      │  
│  Headline                                            │  
│  Supporting Copy                                     │  
│                                                      │  
│  CTA                     Secondary CTA              │  
│                                                      │  
└──────────────────────────────────────────────────────┘  
\`\`\`

Approximate visual balance:

\- 65% Environment  
\- 35% Content

Not because the environment is more important,

but because whitespace is part of the composition.

\---

\#\# Content Column

The content should never stretch across the screen.

Maximum width:

600–680px

Everything should feel comfortable to read.

Never allow headlines to become extremely long.

The left edge of every text element should align perfectly.

Visual discipline creates trust.

\---

\#\# Environment Placement

The visual system should never sit perfectly in the centre.

It should feel intentionally offset.

The composition should resemble editorial magazine layouts.

The environment should create balance,

not symmetry.

\---

\#\# Relationship Between Text & Environment

The environment is not the background.

The typography is not an overlay.

They exist in the same space.

Neither should dominate.

The visitor should feel that the headline belongs inside the environment.

\---

↓

↓

The visitor should never need to search for information.

\---

\#\# Reading Behaviour

The composition should combine:

Editorial reading

\+

Natural visual curiosity

The eye first discovers the environment.

The environment creates curiosity.

The headline answers that curiosity.

Supporting copy builds confidence.

CTA becomes the logical next step.

\---

\#\# Eye Rest

Every strong focal point should be surrounded by calm.

If every area demands attention,

nothing becomes memorable.

Negative space allows the visitor to pause.

\---

\# 07 — Camera Composition

The camera is part of the composition.

Not an animation.

It determines how the visitor experiences space.

\---

\#\# Camera Philosophy

The camera behaves like a calm observer.

Never like a drone.

Never like a video game.

Never like a cinematic trailer.

The visitor should feel present,

not entertained.

\---

\#\# Camera Rules

The camera may:

\- Slowly move forward  
\- Reveal additional depth  
\- Slightly adjust perspective  
\- Settle naturally

The camera must never:

\- Rotate dramatically  
\- Spin  
\- Orbit around objects  
\- Shake  
\- Zoom aggressively

Movement should always feel earned.

\---

\#\# Camera Speed

Movement should be almost subconscious.

If visitors notice the camera,

it is moving too much.

\---

\#\# Stillness

Stillness is a design tool.

The most confident moments should contain almost no movement.

The environment should feel alive,

not busy.

\---

\# 08 — Typography Placement

Typography should feel anchored.

Never floating.

Never detached from the environment.

\---

\#\# Headline

The headline is the strongest visual element after the environment.

Characteristics:

\- Large  
\- Editorial  
\- Calm  
\- Confident

Avoid dramatic multi-line compositions.

Short headlines are more powerful.

\---

\#\# Supporting Copy

The supporting paragraph should immediately reinforce business value.

It should answer:

Why should someone trust Huzaifa?

Avoid explaining technology.

Explain outcomes.

\---

\#\# CTA Placement

Buttons should appear directly below the supporting copy.

Never separated by large gaps.

The relationship should feel conversational.

Headline

↓

Explanation

↓

Action

\---

\# 09 — Choreography

The hero should not reveal everything immediately.

Information appears in layers.

\---

\#\# Sequence

\`\`\`  
Environment

↓

Headline

↓

Supporting Copy

↓

Primary CTA

↓

Secondary CTA

↓

Navigation settles  
\`\`\`

Every reveal should feel inevitable.

Never surprising.

Never theatrical.

\---

\#\# Timing Principles

The environment creates curiosity.

The headline creates understanding.

Supporting copy creates trust.

CTA creates action.

Each stage should complete before the next begins.

Never reveal multiple important elements simultaneously.

\---

\# 10 — Mobile Philosophy

Mobile is not a smaller desktop.

It is a different experience with the same emotional outcome.

\---

\#\# Priorities

On mobile:

Business message becomes more important.

Environment becomes simpler.

Motion becomes lighter.

Reading becomes faster.

The experience should preserve meaning,

not identical visuals.

\---

\#\# Mobile Composition

\`\`\`  
Environment

↓

Headline

↓

Supporting Copy

↓

Primary CTA

↓

Secondary CTA  
\`\`\`

The visual system should compress gracefully.

Never crop away the core idea.

\---

\#\# Mobile Motion

Reduce movement.

Preserve progression.

Users should still feel:

Complexity

↓

Clarity

without relying on large cinematic transitions.

\---

\# 11 — Safe Zones

Never place important content:

\- Too close to screen edges  
\- Behind browser UI  
\- Behind navigation  
\- Inside highly animated areas

The headline should always remain the calmest point of the screen.

The visual system should frame the message,

never compete with it.

\# 12 — Signature Moment

Every memorable digital experience has one moment that visitors remember.

Not because it is flashy.

Because it perfectly communicates the core idea.

The hero should contain exactly one signature moment.

Never two.

Never three.

\---

\#\# The Signature Moment

The experience begins with visible complexity.

Not visual noise.

Business complexity.

A network that lacks organisation.

No centre.

No hierarchy.

No direction.

Then...

One governing principle quietly appears.

The system does not explode into place.

It settles.

Threads align.

Connections become intentional.

Movement becomes predictable.

Nothing is lost anymore.

Visitors should never think:

"Cool animation."

They should think:

"I understand what this person does."

That moment becomes the identity of the portfolio.

\---

\# 13 — Scroll Philosophy

Scrolling is not navigation.

Scrolling is progression.

Every scroll should answer one question before asking the next.

The visitor should never feel rushed.

The visitor should never feel delayed.

Every movement should reward curiosity.

\---

\#\# Progression Rules

Scrolling should:

Reveal

Organise

Clarify

Connect

Guide

Frame

Simplify

Never:

Surprise

Distract

Interrupt

Restart

Reset

Compete

Every scroll should feel like continuing one thought.

\---

\# 14 — Interaction Philosophy

Interactions should create confidence.

Not entertainment.

The visitor should rarely notice interactions consciously.

Instead they should feel:

"This website responds naturally."

\---

\#\# Cursor Behaviour

Cursor interaction is optional.

If used:

\- Extremely subtle  
\- Slow  
\- Physical  
\- Local

Never:

\- Chase the cursor  
\- Create magnetic effects  
\- Produce playful motion  
\- Distort layouts

\---

\#\# Hover Behaviour

Hover should confirm.

Never surprise.

Buttons should feel slightly more tangible.

Nothing should jump.

Nothing should bounce.

Nothing should dramatically scale.

\---

\#\# Motion Hierarchy

Priority order:

1\. User understanding

2\. Readability

3\. Storytelling

4\. Delight

If delight reduces understanding,

remove the delight.

\---

\# 15 — Accessibility & Reduced Motion

The experience must never depend on animation.

Every visitor should receive the same meaning.

Animation may enhance.

It must never explain.

Users who prefer reduced motion should still experience:

Complexity

↓

Clarity

↓

Trust

without missing any information.

\---

\# 16 — Hero Success Criteria

The hero succeeds only if it communicates the following sequence.

\---

\#\# After 3 Seconds

The visitor thinks:

"This feels different."

\---

\#\# After 5 Seconds

"This person builds serious products."

\---

\#\# After 10 Seconds

"This person understands business problems."

\---

\#\# After 20 Seconds

"I trust how this person thinks."

\---

\#\# After 60 Seconds

"I want this person to build my product."

If any stage fails,

the hero must be redesigned.

\---

\# 17 — Hero Failure Checklist

Reject the hero immediately if:

The environment is more memorable than the message.

The animation delays understanding.

The visitor notices effects before content.

Typography competes with visuals.

Buttons attract more attention than positioning.

The experience resembles another portfolio.

The visual metaphor requires explanation.

Technology becomes the story.

The hero feels like a demo reel.

The visitor cannot explain what Huzaifa actually does.

If any of these occur,

the hero has failed.

\---

\# 18 — Design Review Checklist

Before approving any hero iteration, answer these questions.

\#\# Brand

Does this feel like Huzaifa?

Could another developer claim this concept?

Would a founder remember it tomorrow?

\---

\#\# Story

Is there a clear before and after?

Does complexity genuinely become clarity?

Does the visual metaphor support the message?

\---

\#\# Composition

Is there one dominant focal point?

Does the eye move naturally?

Is whitespace doing meaningful work?

\---

\#\# Typography

Does the headline arrive early enough?

Is the supporting copy concise?

Do visitors understand the value before the technology?

\---

\#\# Motion

Does every movement have a purpose?

Could any animation be removed without losing meaning?

Is stillness used intentionally?

\---

\#\# Business

Would a non-technical founder understand it?

Does it communicate competence instead of creativity?

Would it increase trust within the first 10 seconds?

\---

\# 19 — Final Principle

The hero is not designed to impress designers.

It is designed to earn the confidence of people making important business decisions.

Visitors should leave remembering:

Not the animation.

Not the materials.

Not the typography.

But the feeling that they had just met someone capable of bringing order to complexity.

If the hero achieves that,

every other section becomes supporting evidence.
